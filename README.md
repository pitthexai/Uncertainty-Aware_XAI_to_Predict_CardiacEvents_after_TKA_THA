# Uncertainty-Aware_XAI_to_Predict_CardiacEvents_after_TKA_THA

This GitHub repository includes all Python codes, dataset, figures, models, and presentation slides that support the study. Together, these resources provide an uncertainty-aware explainable AI framework to predict 30-day major adverse cardiac events following total knee arthroplasty (TKA) and total hip arthroplasty (THA).  
The framework combines risk prediction, uncertainty quantification, and explainability (SHAP and LIME) to enhance transparency and clinical utility.
We used the NSQIP dataset, focusing on patient-level clinical features. Raw data cannot be shared here, but the code, model structures, and pipeline are provided.

- **Code**: This directory contains all Python scripts and notebooks used for model training, evaluation, and explainability analyses.
